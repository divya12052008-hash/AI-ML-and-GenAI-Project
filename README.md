# LegalEase: AI-Powered Legal Document Generator

LegalEase leverages Generative AI to simplify legal documents creation. Users can generate employment contracts, lease agreements, NDAs, and more tailored to specific inputs like parties, effective dates, and key terms.

Built with FastAPI and Gemini 1.5 Pro, Streamlit frontend.
Features: Editable preview, Custom branding, Export as PDF/DOCX/TXT

Tech Stack: Frontend-Streamlit, Backend-FastAPI, AI Model-Gemini 1.5 Pro, Model: gemini-1.5-pro

Scenarios: Startup founder needs employment contract, Freelancer needs NDA, Landlord needs lease agreement.
